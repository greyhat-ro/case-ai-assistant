Positive Match Record — Data Entry Guide

Demo SOP for entering a confirmed sanctions match into the PMR module.

  1. Confirm the case status is set to 'Under Review' before opening the PMR module — most fields stay locked on any other status.
  2. In 'Match Basis', select the list type that triggered the hit (e.g. BIS Entity List, OFAC SDN) — this unlocks the fields below it.
  3. Enter the matched name exactly as it appears on the source list, then attach the screening report as supporting evidence.
  4. Save as draft before submitting, so a second reviewer can check the entry.
